# Pherdee-boi's Borderlands 2 SDK mods

Python mods for the [Willow2 Mod Manager](https://github.com/bl-sdk/willow2-mod-manager) (not text mods: install them in `sdk_mods`, not through BLCMM).
Made by Pherdee with Claude (Anthropic's AI, through Claude Code). MIT licence (see each LICENSE).

| Folder | What it is |
|---|---|
| `bl3_weapons` | BL3 gun mechanics (Maliwan element switch, Vladof underbarrel, Torgue, Dahl, Tediore, Hyperion, Jakobs, Bandit, anointments, relics) plus the **radiation** and **cryo** elements. Cryo needs a copy of Borderlands: The Pre-Sequel installed to work fully. |
| `adventure_guide` | a sixth status-menu tab listing bosses, special enemies, vendors and chests with the legendaries / uniques they drop |
| `bl3_movement` | BL3 slide and ground slam |

Install: copy the folder(s) into `Borderlands 2\sdk_mods` (so that `sdk_mods\bl3_weapons\__init__.py` exists). Ready-made downloads
(`bl3_weapons.zip`, `adventure_guide.sdkmod`, `bl3_movement.sdkmod`) are on the
[releases page](https://github.com/Pherdee-boi/BLCMods/releases/tag/bl3-mods-2026-10-19). Each folder has its own README.
