# Pherdee-boi's Borderlands 2 SDK mods

Python mods for the [Willow2 Mod Manager](https://github.com/bl-sdk/willow2-mod-manager) (not text mods: install them in `sdk_mods`, not through BLCMM).
Made by Pherdee with Claude (Anthropic's AI, through Claude Code). MIT licence (see each LICENSE).

| Mod | What it is | Download |
|---|---|---|
| [`bl3_weapons`](bl3_weapons) | BL3 gun mechanics (Maliwan element switch, Vladof underbarrel, Torgue, Dahl, Tediore, Hyperion, Jakobs, Bandit, anointments, relics) plus the **radiation** and **cryo** elements. Needs the Willow Texture Loader (texloader) for radiation's gas and bubbles; cryo needs a copy of Borderlands: The Pre-Sequel installed to work fully. | [BL3 Weapons 0.64.6](https://github.com/Pherdee-boi/BLCMods/releases/tag/bl3-weapons) |
| [`adventure_guide`](adventure_guide) | a sixth status-menu tab listing bosses, special enemies, vendors and chests with the legendaries / uniques they drop (beta) | [Adventure Guide 0.9.1](https://github.com/Pherdee-boi/BLCMods/releases/tag/adventure-guide) |
| [`bl3_movement`](bl3_movement) | BL3 slide and ground slam | [BL3 Movement 0.8.0](https://github.com/Pherdee-boi/BLCMods/releases/tag/bl3-movement) |

Install: use the download on each release page, or copy the folder(s) here into `Borderlands 2\sdk_mods` (so that `sdk_mods\bl3_weapons\__init__.py` exists).
Each folder has its own README.
